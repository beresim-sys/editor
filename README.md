# לוח עריכה וסידור סצנות לספר (Scene Flow Editor)

אפליקציית ווב אינטראקטיבית מלאה בעברית (RTL) המיועדת לסופרים ולעורכים, לסידור סצנות הספר ברצף עלילתי, מעקב נקודות מבט (POV), מקום, זמן, וחשיפת מידע עלילתי.

---

## 🌟 תכונות מרכזיות

- **לוח גרירה וסידור מחדש (Drag & Drop)**: גרירה אינטואיטיבית של כרטיסיות סצנה עם עדכון אוטומטי של מספור הסצנות ברצף.
- **מבנה כרטיסיית סצנה עשיר**:
  - מזהה סצנה וכותרת בולטת.
  - תגיות נקודת מבט (POV) בצבעים מובחנים לדמויות (שרה, רפאל, סלווטור, מלכה, מאיר וכו').
  - מקום התרחשות וזמן עלילתי.
  - תקציר עלילה קריא וברור.
  - **מידע שנחשף**: תיבה מודגשת לגילויים, סודות ורמזים עלילתיים.
  - מקור, הערות היסטוריות וטיוטות.
- **טעינה וסנכרון עם Google Sheets**:
  - חיבור ישיר לקישור Google Sheets או ייצוא CSV.
  - טעינת קובץ CSV מקומי.
  - נתוני דוגמה מובנים בעברית לעבודה מיידית.
- **3 מצבי תצוגה**:
  1. **תצוגת רשת (Grid)**: סריקה נוחה ומרווחת.
  2. **תצוגת ציר עלילה רציף (Timeline)**: קריאה רציפה המדמה את קריאת הספר מתחילתו ועד סופו.
  3. **תצוגה קומפקטית (Compact)**: רשימה צפופה לסידור מהיר בין עשרות סצנות.
- **סינון וחיפוש חופשי בזמן אמת**:
  - חיפוש טקסט חופשי בכל שדות הכרטיסייה.
  - סינון מהיר לפי נקודת מבט (POV) עם מונים.
  - סינון לפי מקום ולפי זמן עלילתי.
- **ייצוא מתקדם**:
  - העתקת תקציר מסודר ומעוצב ללוח.
  - העתקת טבלת CSV מוכנה להדבקה מיידית חזרה לתוך Google Sheets!
  - הורדת קובץ CSV עם קידוד UTF-8 מלא (תמיכה מלאה בעברית ב-Microsoft Excel).
  - הורדת גיבוי JSON.
