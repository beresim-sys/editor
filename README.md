# לוח עריכה וסידור סצנות לספר (Scene Flow Editor)

אפליקציית ווב אינטראקטיבית מלאה בעברית (RTL) המיועדת לסופרים ולעורכים, לסידור סצנות הספר ברצף עלילתי, מעקב נקודות מבט (POV), מיקום, זמן עלילתי, וחשיפת מידע עלילתי.

כל כרטיסיות הספר באפליקציה מבוססות על קובץ האקסל המקורי **`סצנות לספר.xlsx`** (124 סצנות מלאות).

---

## 🌟 תכונות מרכזיות

- **מבוסס ישירות על קובץ `סצנות לספר.xlsx`**:
  - טעינה מיידית של כל 124 הסצנות של הספר.
  - כפתור **"איפוס לסדר המקור"** לשחזור 124 הסצנות בכל עת.
  - כפתור **"עדכון מקובץ אקסל"**: אפשרות להעלות קובץ `.xlsx` מעודכן ישירות בדפדפן ולקבל עדכון מיידי.
- **לוח גרירה וסידור מחדש (Drag & Drop)**:
  - גרירה אינטואיטיבית של כרטיסיות סצנה עם עדכון אוטומטי של מספור הסצנות ברצף (`#1` עד `#124`).
  - משוב חזותי בזמן גרירה ושמירה מקומית אוטומטית בדפדפן (`LocalStorage`).
- **מבנה כרטיסיית סצנה עשיר**:
  - מזהה סצנה מקורי (למשל `scene_1`, `scene_2`) וכותרת בולטת בראש הכרטיס.
  - תגיות נקודת מבט (POV) בצבעים ייחודיים לכל דמות (שרה, רפאל שאול, רפאל אלטרס, מאיר דסה, סלווטור, סולטנה, ניסים, מלכה, לואיזה, סוזט ועוד).
  - מיקום ההתרחשות וזמן עלילתי.
  - תקציר עלילה קריא וברור.
  - **מידע שנחשף**: תיבה ייעודית מודגשת לגילויים, סודות עלילתיים ורמזים.
  - מקור (למשל `1 שרה 1`, `7 ניסים 1`).
- **3 מצבי תצוגה**:
  1. **תצוגת רשת (Grid)**: סריקה נוחה ומרווחת של הכרטיסיות.
  2. **תצוגת ציר עלילה רציף (Timeline)**: קריאה רציפה עם קו ציר עלילה המחבר בין כל 124 הסצנות.
  3. **תצוגה קומפקטית (Compact)**: רשימה צפופה המאפשרת סידור מהיר וסקירה קלה בין עשרות סצנות.
- **סינון וחיפוש חופשי בזמן אמת**:
  - חיפוש טקסט חופשי בכל שדות הכרטיסייה.
  - שבבי סינון מהיר לפי דמויות מרכזיות (שרה, רפאל שאול, מאיר, סלווטור, סולטנה, ניסים וכו') עם מחוון ספירה מדויק.
  - סינון לפי כל הרכבי ה-POV, לפי מיקום ולפי זמן עלילתי.
- **ייצוא מתקדם**:
  - העתקת תקציר מסודר ומעוצב ללוח.
  - העתקת טבלה מוכנה להדבקה באקסל / Google Sheets.
  - הורדת קובץ CSV עם קידוד UTF-8 מלא (תמיכה מלאה בעברית ב-Microsoft Excel).
  - הורדת גיבוי JSON מלא.
